# Write Comspares 🚀

**Write Comspares** is a modern, AI-powered electronic comparison web application designed to help users find the best value when purchasing smartphones, laptops, and other tech gadgets. 

## ✨ Key Features
- **Modern Dark-Tech UI:** Sleek, high-performance interface styled with Tailwind CSS.
- **CommanderAI Assistant:** An interactive floating AI chat widget built for showcase to assist users with gadget queries instantly.
- **Dynamic Categories:** Seamlessly explore Mobile phones, Laptops, Smartwatches, and more.
- **Smooth Animations:** Powered by **Framer Motion** for a premium user experience.
- **AI Insights & Ratings:** Detailed comparison metrics and AI-verified specs badges.

---

## 🛠️ Tech Stack
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Routing:** React Router DOM
- **Deployment:** Vercel
